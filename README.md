## ⚙️ Installation & Setup

### Requirements

- PHP
- MySQL
- XAMPP / Local Server
- Web Browser

### Steps

1. Clone the repository:

```bash
git clone https://github.com/Parvez37372/https-divinehealingworld.com.git
```

2. Move the project into the XAMPP `htdocs` directory.

3. Start Apache and MySQL.

4. Create the required MySQL database.

5. Import the project database, if applicable.

6. Update database credentials in the configuration file.

7. Open the project:

```text
http://localhost/divinehealingworld/
```
